# 번역 데이터

빌드가 매번 이 JSON들을 읽어 게임 아카이브로 인코딩합니다. 번역을 고치려면 여기를 고치세요.

| 파일 | 내용 | 들어가는 곳 |
|---|---|---|
| `scenario_ko.json` | 시나리오 대사 (65개 블록) | `data/add03dat.bin` |
| `battle_ko.json` | 전투 대사 | `data/add05dat.bin` |
| `credits_ko.json` | 스태프 크레딧 142개 | `overlay/ovl_003` |

## 왜 한국어만 있나요

작업용 파일에는 번역 참고용으로 일본어 원문이 `jp` 필드에 함께 들어 있었습니다. 그건 **게임의 원본 스크립트**라서 재배포하지 않습니다. 여기 올라온 것은 한국어만 남긴 판본입니다.

빌더는 `jp`를 **읽지 않으므로** 결과물은 완전히 동일합니다 — `build_native.py` / `build_battle.py`로 양쪽을 빌드해 바이트 단위로 같음을 확인했습니다.

일본어 원문을 옆에 놓고 번역하고 싶다면 본인 ROM에서 복원하세요:

```bash
python srwk_work/extract_roms.py    # 아직 안 했다면
python srwk_work/restore_jp.py
```

`srwk_scenario_clean.json` / `srwk_battle.json`이 만들어지고, 그 파일이 있으면 빌드가 자동으로 그쪽을 씁니다.

## 편집 규칙

- **`ko`만 고치세요.** `c1`(화자/초상화) `c2`(플래그) `name` `sec` `sp` 는 빌드에 쓰이므로 그대로 둡니다.
- **줄당 176 px** — 한글 12 px, 반각 8 px. 시나리오는 **최대 3줄**.
- **①②③ 같은 동그라미 숫자는 자리표시자입니다.** 게임이 실행 중에 캐릭터 이름으로 치환합니다. 번역하거나 지우지 마세요.
- 전투 대사는 반각 `!` `…` `。` `·` 사용 (전각 `！？　，、`는 테이블에 없음).
- **크레딧은 일본어 원본 길이를 넘길 수 없습니다.** 넘기면 엔딩이 깨지고 멈춥니다. `_inject_credits_fit.py`가 검사하며, 긴 인명은 성만 남깁니다.
